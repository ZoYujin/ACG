# CHAIR evaluation data

`chair_image_ids.txt` records the fixed 500-image MS COCO validation subset used
for the reported LLaVA-NeXT results. One numeric COCO image ID appears per line.

Download the COCO 2014 validation images separately and pass their directory to
`eval/chair_generate.py --image-folder`. COCO images and annotations are not redistributed here.
